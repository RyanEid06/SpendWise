## Confirmed defect and precise repair

Owner evidence: HONOR X9d, Android 16/API36, com.spendwise.app, signed 2.0.2/code8.
The supplied report contains nine matching exception chains. The raw report is
kept outside tracked source; SHA256:
`5428ad47b6684ae1297d293219e49b680035af949070b388ed611495d95807c4`.

Original chain: MainActivity.attachBaseContext:15 →
SpendWiseAppearance.restoreBeforeActivity:47 → applyNightMode:52 →
ContextImpl.getSystemService → UiModeManager constructor →
ContextWrapper.getApplicationContext (null base context). Calling the service
before Activity attachment allowed Android 16 to resolve its outer Activity while
that wrapper was still uninitialized.

MainActivity and SpendWiseAppearance now split restoration at the lifecycle boundary:
API30 and earlier set AppCompat's local mode before resource attachment, without
fetching UiModeManager. API31+ restore through the initialized application context
in onCreate, after attachment and before SplashScreen.installSplashScreen and
Capacitor super.onCreate. All modern mode changes use the application context.
Configuration changes update surfaces without applying the mode again. There is
no catch that hides a service/initialization exception.

The Java boundary regression first reproduced the exact pre-attachment NPE with
API36 context doubles, then passed the corrected production Java. It exercises
SDK30/31/36, LIGHT/DARK/SYSTEM/invalid preference, OS light/dark, configuration,
relaunch, native surfaces, plugin mode changes and secure-window preservation.
This fast test complements actual Android execution; it is not hardware evidence.

## Focused provider security hardening

The pre-existing FileProvider mapped entire shared external storage and all cache.
Mappings now allow only app-owned external-files Pictures/ (current camera capture)
and cache/shared/ (explicit user exports). Current camera/gallery options disable
editing, so the unused legacy crop cache path is not required by the app.
Text/blob exports create or reuse that dedicated directory, constrain filenames to
the final component, reject invalid names, and share the actual Filesystem URI.

Node export regressions went red on the original roots and pass after narrowing.
Android framework instrumentation tests allow legitimate camera/export URIs and
deny private files/databases, WebView/draft cache, cache siblings, general external
storage, traversal and symlink escape. Their real API36 execution is a required
separate debug instrumentation gate, not signed release launch evidence.

SQLCipher/Keystore parameters, database schema/migration behavior, encrypted private
media, credentials and financial recovery are unchanged. Synthetic emulator resets
are guarded by emulator serial, QEMU, exact AVD and API; they must never run against
the owner's phone. Physical upgrade requires installation over code8 without
uninstalling, clearing data or resetting credentials.
